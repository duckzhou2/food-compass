# 北大食堂数据说明

## 正式统计

- 14 个官方组织机构餐饮单位，另保存 1 个移动餐车服务点。
- 31 个楼层/结构节点，其中 19 个为可靠物理楼层。
- 79 个官网抽取的窗口、档口或经营类别。
- 650 个按“食堂 + 楼层 + 标准化基础名”形成的菜品。
- 514 个 GitHub 历史 SKU，逐文件数量与资料包一致。
- 427 个菜品没有可靠窗口关联，统一显示“窗口待确认”。

## 清洗与合并

- 食堂名称使用登记表统一，原别名进入搜索字段；昌平园的三种官方名称指向同一实体。
- `*1/*2/...` 与小、中、大份从菜名中提取为份量；原始名称和每条 SKU 均保留。
- 不跨食堂或楼层合并同名菜，不把不同份量折叠成一条价格/营养记录。
- GitHub 的局部 ID 与来源文件组合成全局稳定 ID；菜品 ID 使用确定性哈希。
- 官网有明确窗口的菜品关联该窗口；GitHub 菜品不根据名称自动套用官网窗口。
- “未公开完整菜单”“按100克计价”“每餐若干种”等聚合描述保存在窗口说明中，不计作具体菜品。
- 将来源中粒度混乱的菜系词统一为 14 个互斥的“风味分类”：家常中餐、点心烘焙、汤粥轻食、川渝麻辣、西北新疆、西式餐食、湘赣风味、粤式烧腊、江浙淮扬、东北风味、东南亚风味、日韩料理、饮品甜品、京鲁北方。
- 650 个菜品均依据名称、原始菜系和细分类归入且只归入一个风味分类；统一分类标记为推断，原始菜系另存于 `rawCuisines`，不覆盖或删除来源内容。

## 状态边界

- 2025–2026 官方资料标记为当前官方；2022 及更早页面标记为官方历史。
- 514 条 GitHub 价格与每份营养均标记为历史参考，采集日期、份量克重和测算来源未注明。
- 统一风味分类和仅由名称规则得到的细分类属于推断；价格、营养、辣度等其他缺失值保持缺失。
- 临时活动独立保存，默认不进入日常推荐。

原始资料统一保存在父目录的 `资料源/北大食堂/`。执行 `pnpm import:canteens` 会重新生成目录并验证原始行、文件数量、唯一 ID 与全部关联；任一硬校验失败都会中止。
