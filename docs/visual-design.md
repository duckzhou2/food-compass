# 食物罗盘视觉规范

## 方向

现代东方茶饮 × 年轻消费品牌 × 有重量感的转盘体验。界面应像一张克制的当代茶饮菜单：温暖、可信、留白充足，不使用科技紫渐变、玻璃拟态、无意义插画或通用 SaaS 卡片阵列。

## 色彩

| Token | 色值 | 用途 |
|---|---|---|
| 奶油纸色 | `#F8F5EE` | 页面底色 |
| 深茶绿 | `#173F35` | 主标题、主按钮、转盘基色 |
| 玉绿色 | `#176B55` | 链接、数据条、辅助强调 |
| 焙茶金 | `#E8A54B` | 少量高光、指针、提示 |
| 果浆红 | `#C96348` | 关键动作与结果揭晓强调 |
| 墨色 | `#1D241F` | 正文 |
| 暖灰 | Stone 色阶 | 次级文字与分隔 |

强调色总面积应小于页面可视面积的 15%。不使用大面积渐变；允许低透明度的单色径向光晕为奶油底增加纸张温度。

## 字体与层级

- 中文展示标题：系统宋体栈，由 `font-serif` 表达茶文化气质。
- 正文与控件：系统无衬线字体，保证小屏可读性。
- 数字：等宽字体，用于热量、记录数和统计值。
- H1：手机 44–48 px，桌面 64–72 px；行高约 1.05。
- H2：28–40 px；正文 15–18 px，行高 1.7–1.9。
- 英文眉题只作轻量导航，字号 10–12 px、增加字距。

## 形状、边界与阴影

- 主罗盘为真正的圆，外圈以实体白边和单层暖色阴影承重。
- 大区域圆角 28–40 px；控件 12–16 px；胶囊只用于模式切换或状态，不滥用。
- 优先用留白、底色和细分隔线组织信息；不把每段内容都放入卡片。
- 阴影仅用于罗盘、主结果与悬浮关键动作，其他区域保持平面。

## 间距

- 页面水平边距：手机 16 px，平板 24 px，桌面 32 px。
- 章节纵向间距：手机 48–64 px，桌面 72–96 px。
- 信息组内间距使用 8 / 12 / 16 / 24 / 32 px 节奏。
- 首页首屏不叠加统计卡或功能卡，保持单一叙事焦点。

## 动效

- 罗盘旋转 2.4 秒，使用 `cubic-bezier(.12,.66,.18,1)`，前快后稳，模拟实体重量。
- 结果只在同一次随机选择完成后揭晓，不二次抽取。
- 普通 hover 位移不超过 2 px；不使用持续漂浮或闪烁。
- `prefers-reduced-motion: reduce` 下将旋转缩短为 80 ms，并移除非必要过渡。

## 响应式与单手操作

- 375 px：筛选默认折叠为一个易触达入口，罗盘不小于可用宽度的 88%，主按钮位于圆心。
- 768 px：维持单列主叙事，筛选可展开但不挤压罗盘。
- 1440 px：筛选为左侧辅助栏，罗盘和结果为绝对视觉中心。
- 触控目标至少 44 px；热量模式、转动按钮和重置入口无需精细点击。

## 结果与缺失数据

- 揭晓区第一层只强调品牌、产品名、热量与四项主要规格。
- 完整营养、来源、审计说明收进次级展开区，避免证据淹没结果。
- `null` 统一自然显示为“待核验”，并通过一行解释消除“页面残缺”观感。
- 非官方、媒体转述与估算必须在次级证据区明确标注，不改变其来源属性。
