# 视觉 QA 记录

检查环境：系统 Chrome（Playwright 控制），视口宽度 375 / 768 / 1440 px。截图输出到 `artifacts/visual-qa/`，该目录不进入版本管理。

## 第一轮

- 首页：桌面首屏构图稳定，标题与核心视觉关系明确；移动端内容顺序自然。
- 罗盘：三种宽度均无横向溢出；375 px 下转盘占据主视觉，筛选默认折叠。
- 结果：品牌、产品名、热量和主要规格先展示；详细营养和来源默认折叠。
- 空状态：可见且提供恢复提示；移动端展开筛选后可单手操作。
- 控制台：0 error。

发现并修正：

1. 375 px 品牌名被挤成两行：移动端隐藏重复的“首页”和次要“关于”导航，品牌名禁止换行。
2. 转盘单个紫色扇区偏科技感：替换为低饱和浆果红。
3. 1440 px 罗盘仍可更突出：最大直径由 470 px 提升至 540 px。
4. 长页面截图中 sticky 导航受当前滚动位置影响：每个状态截图前强制回到页面顶部。

## 第二轮验收项

- 再次确认三档首页和罗盘无横向溢出。
- 复核 375 px 品牌、导航和标题换行。
- 复核 1440 px 转盘与筛选栏的主次关系。
- 复核结果与详情展开状态、移动端空状态、长链接入口。
- 记录控制台错误数量并执行最终 lint / typecheck / test / build。

## 第二轮结果

- 375 px：品牌名保持单行，导航保留“奶茶罗盘”和“数据透明度”两个必要入口；首页和结果卡无横向溢出。
- 768 px：首页标题、按钮与核心视觉依次进入首屏，文字没有异常孤行。
- 1440 px：罗盘直径提升后成为页面主视觉，筛选栏保持辅助层级。
- 空状态、结果状态和详情展开状态均完成截图；来源使用短链接文案，没有长 URL 撑破布局。
- 三档 `homeOverflow=false`、`wheelOverflow=false`，控制台错误均为 0。

第二轮未发现需要继续调整的阻断性视觉问题。
